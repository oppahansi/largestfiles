# Security

The plugin adds one API endpoint, `GET /LargestFiles/Report`, which requires an administrator session or API key and only reads library data.

If you find a security problem, please don't open a public issue. Report it privately through [GitHub security advisories](https://github.com/oppahansi/largestfiles/security/advisories/new). Fixes go into the latest plugin version for every supported Jellyfin line.
